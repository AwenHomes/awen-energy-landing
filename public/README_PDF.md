# PDF File Placement

Please add your `SunPower_Bankruptcy_Survival_Guide.pdf` file to this directory.

The guide page at `/sunpower-bankruptcy-guide` expects the PDF to be located at:
`/public/SunPower_Bankruptcy_Survival_Guide.pdf`

This will make it downloadable from the website at the URL:
`https://yourdomain.com/SunPower_Bankruptcy_Survival_Guide.pdf`
